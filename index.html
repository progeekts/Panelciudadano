Una fuente “accesible” significa que Panel Ciudadano pudo consultarla; no implica que todos sus servicios estén operativos. Los fallos del robot se separan de las incidencias confirmadas para evitar falsas alertas.

Información para orientarte, con trazabilidad.

Cada ficha indica su procedencia. Una convocatoria detectada no se presenta como abierta si no podemos verificar el plazo. Una caída solo se publica como incidencia cuando existe una señal oficial suficiente. Los avisos alimentarios y sanitarios se muestran como publicaciones oficiales, sin inferir que una retirada continúe vigente. Antes de realizar un trámite, pago o actuación, consulta la fuente enlazada.
